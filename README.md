# MeowCacheCleaner

![Visitors](https://api.visitorbadge.io/api/visitors?path=https%3A%2F%2Fgithub.com%2Fmatvey2222222222%2FMeowCacheCleaner&label=%20Просмотры&countColor=%23263759&style=flat-square)

Со временем временные и кэшированные файлы занимают много места и могут замедлять работу программ. MeowCacheCleaner не удаляет всё подряд: сначала он сканирует диск, показывает, что найдено, и только потом ты решаешь, что очистить.

## Главная особенность: сначала сканирование, потом очистка

Вместо автоматического удаления программа работает в два этапа:

1. **Кнопка «Сканировать кэш»** — запускает анализ выбранных директорий.
2. **Результаты сканирования** выводятся в виде списка с категориями:
   - **Кэш и временные файлы** — безопасно удалять.
   - **Возможно важные** — файлы, которые лучше не трогать без проверки.  
   Ты видишь, что именно будет удалено, и подтверждаешь только нужные категории.

Такой подход защищает личные данные и даёт полный контроль над процессом.

## Что умеет программа

- **Очищает кэш браузеров** — поддерживает Chrome, Edge, Firefox. Удаляет временные файлы, накопленные при просмотре страниц.
- **Чистит системные папки Temp** — удаляет временные файлы Windows, которые остаются после обновлений, установок и работы приложений.
- **Удаляет кэш лаунчеров и игровых клиентов** — помогает освободить место для популярных клиентов (Steam, Epic Games и др.). Если у тебя стоит собственный лаунчер, MeowCacheCleaner может быть полезен и для него.
- **Работает точечно** — программа не удаляет личные данные (документы, фото, загрузки) и не затрагивает важные системные файлы.

## Как запустить

1. Скачай последний релиз из вкладки **Releases**.
2. Запусти `CacheCleaner.exe`.
3. Нажми кнопку **«Сканировать кэш»** и дождись завершения анализа.
4. Посмотри результаты: выбери категории для очистки.
5. Нажми **«Очистить»** и проверь, сколько места освободилось.

💡 Для работы не требуются права администратора в большинстве случаев, но максимальный эффект достигается при запуске от имени администратора (особенно для очистки некоторых системных папок).

## Важное предупреждение

Антивирусы (в том числе Windows Defender) могут помечать `CacheCleaner.exe` как подозрительный файл. Это ложное срабатывание, которое связано с тем, что программа собрана с помощью PyInstaller и выполняет операции массового удаления файлов — такое поведение антивирусы часто считают «подозрительным».

Если ты скачал файл из официального релиза на этой странице, он безопасен.

## Почему это может быть полезно

- Освободить несколько гигабайт места, которые незаметно «съедаются» кэшем.
- Ускорить запуск браузеров и некоторых программ.
- Подготовить систему к установке новых игр или обновлений.
- Держать под контролем, что именно удаляется, без слепого доверия автоочистке.
